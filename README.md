# 할수있어

매일 루틴과 오늘 할 일을 체크하고, 매시 정각에 남은 일을 알려주는 웹앱입니다.

- 앱 주소: https://taichen2k.github.io/candoit/
- 기록은 각 기기 안에만 저장됩니다. 기기를 바꿀 때는 설정 → 백업 · 복구를 쓰세요.
- 서버 백업: 깃허브 **비공개** 저장소(예: candoit-backup)의 `backups/` 폴더에 최근 3개를 보관합니다. 접근 토큰은 각 기기에만 저장되고 이 저장소에는 올라오지 않습니다.
- 잠금화면 알림은 외부 타이머(cron-job.org)가 매시 00분에 GitHub Actions(`매시 정각 알림`)를 직접 실행시켜 보냅니다. 깃허브 자체 예약 실행은 시각이 부정확해서 끔.
  - 저장소 비밀값 `VAPID_PRIVATE_KEY`: 알림 서명 키
  - 저장소 비밀값 `PUSH_CODES`: 앱 설정에서 복사한 알림 코드 (기기마다 한 줄)
